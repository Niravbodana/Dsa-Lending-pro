# NeerCred truck-support branding video

12-second cinematic vertical (9:16) ad.

## Story
1. The black truck — **YOUR FINANCIAL CONDITIONS** — loses balance to its **right** (viewer’s right, clockwise from the rear dashcam). Left wheels lift; right tires stay planted. It never self-corrects.
2. The **NeerCred** truck enters from the **right** and physically braces that falling right flank.
3. Only then both drive upright, side by side.
4. Exact NeerCred brand page (approved amount ₹5 Lakh / Apply now) — pixel-locked, never regenerated.

## Files (phone / QuickTime / WhatsApp)
These MP4s include a silent AAC audio track and H.264 **Main** profile so iPhone and QuickTime will open them:

- `NeerCred-truck-support-9x16.mp4` — 1080×1920
- `NeerCred-truck-support-9x16-720.mp4` — 720×1280 (smallest, most compatible)
- `NeerCred-truck-support-9x16-4K.mp4` — 2160×3840

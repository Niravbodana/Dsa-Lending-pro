# NeerCred Logo

**One official lockup** — transparent SVG, used everywhere via `<NeerCredLogo />`.

| File | When |
|------|------|
| `neercred-horizontal.svg` | Header, light pages (default) |
| `neercred-horizontal-light.svg` | Footer, dashboard (`dark` prop) |
| `neercred-icon.svg` | Browser favicon only |

## Usage

```tsx
<NeerCredLogo />              // header, light bg
<NeerCredLogo dark />         // footer, dark bg
```

Tagline in logo: **Dream Big · Borrow Smart** (gold, below NeerCred).

See [BRAND-SAFETY.md](./BRAND-SAFETY.md) for conflict check notes.
